# Эволюционное программирование и генетические алгоритмы

Четыре лабораторные работы по комплексу Р. В. Душкина, МИФИ.
Группа 517, номер 14, Q=1, Y=26: **вариант 12**.

| Работа | Реализация | Материалы |
|---|---|---|
| 1 | Вещественный ГА, функция Цин в 5 измерениях, BLX, два масштаба мутации, случайный поиск | [Отчёт](lab1/REPORT.md) |
| 2 | Доставка по 20 точкам с ограничением времени, OX, инверсия/обмен, два штрафа | [Отчёт](lab2/REPORT.md) |
| 3 | Расписание 24 занятий, NSGA-II, три критерия и сравнение со взвешенной суммой | [Отчёт](lab3/REPORT.md) |
| 4 | Самоадаптирующаяся покоординатная ES, сравнение с фиксированным шагом на двух функциях | [Отчёт](lab4/REPORT.md) |

Ключевые операторы, отбор, недоминируемая сортировка и гиперобъём реализованы в исходном коде.
Готовые пакеты оптимизации не используются. NumPy служит для массивов и генератора случайных чисел,
Matplotlib — для графиков. Отчёты представлены в разрешённом формате Markdown.

## Установка и полный запуск

Требуется Python 3.10 или новее.

```console
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Linux/macOS:

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

В активированном окружении:

```console
python run.py --lab 1
python run.py --lab 2
python run.py --lab 3
python run.py --lab 4
python -m unittest discover -s tests -v
python verify_results.py
```

Полная серия включает 20 запусков каждой конфигурации ЛР1–3 и 30 — ЛР4, суммарно 300 запусков.
Готовые результаты включены: для чтения отчётов повторный расчёт не требуется.
В `config.json` заданы бюджеты, размеры популяций и параметры индивидуального варианта.
`python run.py --seed 13000` задаёт новую серию; `--runs 2` позволяет быстро проверить запуск,
но перезаписывает результаты выбранных работ короткой серией.
`python run.py --plots-only` пересоздаёт отчёты и графики по сохранённым результатам.
Точное время зависит от машины. Время подготовки графиков не входит во время поиска.

## Структура

- `evolution/` — алгоритмы и предметные модели;
- `tests/` — независимые проверки математических свойств и бюджетов;
- `lab1/`…`lab4/` — отчёты, инструкции, данные, таблицы всех запусков и графики;
- `lab4/PROPOSAL.md`, `lab4/DEMO.md` — заявка и сценарий защиты;
- `environment.json` — версии среды измеренного эксперимента;
- `reports.py` — воспроизведение отчётов на основе фактических результатов.
- `verify_results.py` — проверка статистик, бюджетов и сохранённых решений без повторения поиска.

Синтетические данные генерируются с seed 10114 и приложены в JSON.
Seed каждого запуска указан в CSV; число оценок включает начальную популяцию.
Сравнение методов внутри каждой работы проводится при одинаковом бюджете вычислений целевой функции.
Битовая идентичность между разными версиями NumPy не гарантируется; параметры и данные позволяют получить сопоставимые результаты.

Методичка предусматривает последовательную защиту работ. Наличие реализации не означает утверждение темы проекта или получение оценки.
Альтернативный интерактивный симулятор заменяет комплекс из четырёх работ и в этот комплект не включён.
